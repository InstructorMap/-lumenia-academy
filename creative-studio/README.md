# YUNA Creative Studio — fase 1

Motor editorial y de recursos para YUNA Sound Holistic y YUNA Academy, **sin modificar el campus, la web ni la APK**.

## Flujo editorial
1. Brief de campaña y público objetivo.
2. Selección de recursos del catálogo (logos, cursos, referencias).
3. Revisión de derechos: el inventario no equivale a autorización de uso.
4. Guion y storyboard con 3 escenas visualmente diferentes como mínimo por Short.
5. Montaje con originales aprobados. No generar música procedural para simular las pistas de Sakura/Kyoto.
6. Control técnico automatizado y revisión artística humana.
7. Publicación **solo con aprobación explícita**.

## Reglas creativas
- No repetir un clip de ocho segundos como único fondo de un video largo.
- No crear tres Shorts que solo cambian el texto.
- No colocar logos sobre cajas genéricas; usar archivos originales y respetar proporciones.
- Publicidad: mostrar portada real del curso y CTA hacia YUNA Academy.
- El video largo prioriza la experiencia musical; promoción discreta al cierre y descripción.
- No afirmar certificaciones, precios, matrículas ni descuentos sin comprobar su vigencia.

## Estado
El repositorio contiene recursos visuales y workflows. Este módulo **organiza la producción y valida archivos**, pero todavía NO genera imágenes cinematográficas nuevas ni garantiza calidad artística automáticamente.
